Windows 11 原生设置风格的任务栏与资源监控工具。当前版本 **0.6.1 安装预览版**。

## 安装与启动

安装包：`E:\haoyue\cache\claribar\artifacts\ClariBar\releases\ClariBar-Setup-0.6.1-x64.exe`，适用于 Windows 11 x64。安装向导提供简体中文和英文，支持系统深浅色、开始菜单入口、桌面快捷方式与标准卸载。

默认软件目录为 `E:\haoyue\cache\claribar\programs\ClariBar`，运行数据默认继续使用 `E:\haoyue\cache\claribar`，均可在向导中选择。已有颜色、字体、布局与指标选择会继续使用；卸载只移除安装程序拥有的文件，保留运行数据和个人设置。

安装包自带 .NET 10 x64 与 Windows App SDK，不需要 Visual Studio、SDK、开发脚本或全局 .NET。首次安装在没有 PawnIO 的电脑上可选择安装官方签名的硬件传感器组件；该步骤需要 Windows 管理员授权。已安装的共享 PawnIO 不会被替换或随澄栏卸载。

本安装预览版尚未使用代码签名证书签名。校验值保存在同名 `.exe.sha256` 文件。验证范围见 `docs/0.5安装包与品牌验证.md`。

## 从源码构建

双击根目录 `启动澄栏.cmd`；首次或代码修改后运行 `构建澄栏.cmd`。也可以在开发终端执行：

```powershell
& .\scripts\build.ps1 -Check -UiCheck -TaskbarCheck
& .\scripts\run.ps1
```

构建结果：`E:\haoyue\cache\claribar\artifacts\ClariBar\0.6.1\ClariBar.exe`。请使用启动脚本，以便正确加载 E 盘的 .NET 和缓存配置。需要保持 E 盘连接。构建复用此前配置的 Visual Studio、Windows SDK、.NET、CMake、Ninja 与 NuGet 缓存。

生成可安装 EXE：运行 `scripts/package.ps1`。该脚本创建 SVG 同源的多尺寸图标、发布自带运行库的界面与采集器、编译 Inno Setup 向导和设置 E 盘临时目录的 C++ 安装引导程序。Inno Setup 工具、包下载和发布中间结果均放在原定缓存目录。

Visual Studio 可打开根目录 `ClariBar.slnx`。管理员采集联调可运行 `scripts/build.ps1 -Check -ElevatedCheck`，它会显示 Windows UAC 请求；取消授权不会自动授予权限。日常启动默认使用普通权限，按需点击界面的“授权硬件访问”。

## 当前功能

- 侧栏顶部显示应用图标和名称，口号移至底部版本号上方；概览移除重复功能说明。关于页提供 Haoyue 作者信息、邮箱、MIT、GitHub 和赞助感谢入口。

- 顶栏合并为一条原生窗口工具栏，保留当前浅色顶栏 #ECF6F9 与原有灰色底色，主体使用圆角分层；深色与高对比度资源随主题切换。
- 顶栏提供帮助菜单、F1 使用帮助、Ctrl+F 查找传感器、Ctrl+B 折叠导航。图标导航保留名称提示，折叠偏好会保存。
- 六个页面适应窗口宽度：筛选区、设置项、概览卡片、配色方案和预览标题自动换行；窄窗口使用紧凑传感器列表。
- 页面切换、导航折叠与主题切换加入过渡动画，遵循 Windows 系统动画设置。关于页精简重复名称和 Logo，版本位于标题右侧及导航底部。

- 设置页内置实时任务栏预览，可切换深浅桌面并放大预览，监控使用真实数据，系统图标为配色示意。
- 资源监控标题右侧提供唯一的授权/重连按钮：等待授权、连接、读取时显示进度并禁用，收到实际硬件授权数据后变为“重新连接”。旁边与状态栏同步展示当前采集状态。
- 资源监控筛选区使用“全部类别”“常用指标”“全部硬件”区分类别、指标范围和具体硬件；数量与无读数通道开关位于右侧。
- 原生 WinUI 设置窗口：概览、任务栏外观、资源监控、文字与图标、通用设置、关于。
- 独立进程实时采集 CPU、GPU、物理内存、磁盘、默认物理出口及主板传感器。常用列表只保留整机占用、CPU/GPU 主温度、各盘活动与读写、物理出口上下行，排除每核心/线程、虚拟内存和次要 GPU 引擎。
- 网速直接读取 Windows 物理接口 64 位收发计数器，按物理默认路由及“路由跃点数 + 接口跃点数”选择出口；优先 IPv4，无 IPv4 时使用 IPv6。每次采样重新检查路由，切换网卡或计数器重置时重新建立基线。过滤虚拟、隧道、回环和驱动过滤接口，不累加 VM、WSL、Hyper-V 网卡。
- 点击“授权硬件访问”仅提升采集进程，设置界面不提权；授权成功后记住启动偏好，下次启动由 Windows 再次显示 UAC。取消或提升失败时自动继续基础采集，不循环弹窗。“通用设置”可关闭启动授权。
- 不再把缺少权限统一显示为不可用；高级无读数通道默认隐藏，可勾选“显示无读数通道”检查。CPU 温度/频率和磁盘详细数据需要硬件授权；GPU 未提供独立温度时明确说明原因。
- 按设备、类别、指标和名称筛选；固定最多 8 项、重命名指标；断开或过期时显示 —。
- Windows 11 XAML 任务栏背景：跟随系统、全透明、半透明着色；颜色与不透明度可调。
- 真正内嵌监控：在系统托盘布局中添加监控子项并分配空间，各显示器任务栏均可显示。
- 最多 8 项监控可采用单行、双栏（两列）、双行（两行）；默认按每列文字测量宽度，避免等宽布局截断长名称。关闭自动宽度后可手动设为 100–900 逻辑像素。
- 监控指标使用中文，保留 CPU、GPU 和标准单位；设备型号、原始传感器名称与标识保持不变。列表支持中文搜索，悬停可查看原始名称。
- 每项文字可分别设置颜色；新增一键随机配色和冰川蓝、薄荷绿、落日橙、柔雾紫 4 套预设，可选择作用于监控、系统文字图标或全部。
- 支持本机已安装字体、统一加粗和 8–24 字号；字体、粗细、字号同时作用于任务栏内嵌监控、独立窗和预览。
- 字号输入后按回车或点击空白处即可保存并结束编辑，切换页面或离开窗口也会保存。上下调整按钮固定在输入框内，避免悬浮按钮残留；无效输入恢复已保存值，超范围输入限制为 8–24。
- 内嵌监控和预览按实际字形范围安排各行，预留 4 个逻辑像素的行间净空，包含中文、重音和下伸字符。内嵌区域读取每块任务栏实际背景范围，多行文字最多上移 2 个逻辑像素；空间不足时限制上移并缩小字号。系统配色设置分别使用时间、日历、托盘、网络、音量、键盘和电池图标。
- 鼠标默认穿透；关闭穿透后独立监控窗可拖动。内嵌区域按实际任务栏高度限制字号，指标过多时自动收紧以避免越界。
- 时间、日期、系统托盘字形、网络、声音、输入法和电池可分别设置颜色；单项颜色优先于托盘通用颜色，关闭后恢复原始属性。
- 系统托盘入口、关闭隐藏至托盘、彻底退出、主题与采样周期、配置保存和诊断导出。托盘菜单可单独开关内嵌监控与独立监控窗。

## 使用方法

1. 打开“任务栏外观”，将背景样式设为“全透明”，开启“嵌入 Windows 任务栏”。
2. 在“资源监控”中选择需要固定的指标，最多 8 项；可重命名。
3. 在“文字与图标”预览当前效果，可一键随机或选择 4 套配色。继续向下可逐项设置颜色、字体、加粗、字号、布局和自动宽度，也可启用时间、日期、网络、声音和输入法颜色。
4. 需要恢复系统外观时，在“任务栏外观”点击“全部还原”；从托盘彻底退出也会恢复。关闭窗口默认隐藏至托盘，效果继续生效。

## 适配范围与边界

本次实际验证系统为 Windows 11 25H2 / 26200.9711，两块显示器。任务栏内部控件可能随 Windows 更新变化，其他构建需以界面中的实际匹配状态为准。任务栏透明、内嵌和配色使用系统 XAML Diagnostics 接入 Explorer，不安装开机项、计划任务或常驻服务。

系统配色覆盖文字、FontIcon 字形与 Path 图标；第三方程序提供的彩色托盘位图暂不重绘。本机没有匹配到电池控件，因此电池颜色未完成实机验证。开机启动和历史曲线仍待开发。

退出或失联时会移除本程序插入的监控布局、还原修改前的属性与绑定；主进程心跳中断约 6 秒后自动恢复。为保证回调安全，适配 DLL 固定留在当前 Explorer 进程内，此后保持闲置，直至 Explorer 自然退出才由系统卸载。它不等同于退出时立刻卸载 DLL；磁盘上按哈希保存的适配模块是有意保留的，避免覆盖被 Explorer 加载的文件。

& .\scripts\probe-taskbar.ps1 -Apply -Extended -Adaptive -Watchdog

## 权限与数据

主板温度/风扇和 CPU 温度可能需要管理员权限。风扇统计为可读取通道；0 RPM 可能代表未连接或停转，不能据此确定实际风扇总数。核显温度若无独立传感器返回，则保留不可用，绝不用 CPU 温度替代。采集只读，不调整转速、电压或功率。

采集器通过当前用户专用命名管道和随机会话令牌通信，只接受采样命令；UI 断开后退出，20 秒未收到心跳也会退出，不安装常驻服务或计划任务。

旧版本固定到某张 `/nic/` 网卡的上下行会自动迁移为默认物理出口，保留对应颜色、名称与顺序。

配置：`E:\haoyue\cache\claribar\data\settings.json`；日志与检查结果：`logs`。现有全局环境变量、代理选择、其他缓存目录和 CTM 安装不变。

使用 Git 时复用本项目开发终端配置：E 盘 exFAT 不记录所有者，本项目的安全目录例外仅写入专用的 `E:\haoyue\cache\claribar\caches\git\config`，没有改动其他工具的 Git 配置。
