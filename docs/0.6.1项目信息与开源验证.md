自带运行库的发布版本执行 --smoke-test，覆盖六个页面、24 组窗口宽度/页面组合、字号编辑、帮助和过渡动画；另检查作者、邮箱、GitHub/邮件入口、赞助说明以及实际显示的 MIT 许可证。结果保存在缓存 logs\claribar-project-info-check.json。

项目链接测试检查 URI，不自动启动浏览器或邮件应用。许可证窗口由本程序实际打开并渲染为 project-license.png；关于页截图为 about-project.png。两者均位于缓存的 artifacts\ClariBar\screenshots。

源码仓库延续 GitHub 原有的 main 初始提交；开发环境入口脚本随源码提供，其他脚本从仓库内加载。当前脚本默认沿用 E:\haoyue\cache\claribar 下的工具与缓存目录；其他电脑需要按其工具安装位置调整开发环境入口。最终用户使用自带运行库的安装包，不需要这些开发工具。

SSH 身份仅保存在本机用户 SSH 目录及仓库本地 Git 配置中，不包含在项目源码或安装包里。
