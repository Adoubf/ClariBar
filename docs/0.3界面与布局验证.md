# 0.3.0 预览、中文、宽度与文字样式验证

日期：2026-10-27。系统 Windows 11 25H2 / 26200.9711，双显示器。所有工具、缓存、临时文件和输出仍在 `E:\haoyue\cache\claribar`，源代码仍在 `E:\haoyue\myproject\home\ClariBar`。

## 本次修改

- 任务栏外观与文字配色页面均有完整的实时任务栏预览，支持深浅桌面背景和放大预览。监控读取实时采集数据；开始/搜索/文件夹和系统图标用于示意。
- 中文显示名称用于列表、名称选择器、颜色选择器、中文搜索和监控。保留 CPU/GPU 与单位；原始硬件名、传感器名和标识不被翻译覆盖，原始名称可在列表提示中查看。用户自定义名称优先。
- 监控默认按每列最长文字测量宽度，纳入所选字体、字号、加粗和间距；按任务栏可用空间设置上限。过长内容达到上限时允许省略，以保证其他任务栏内容有空间。手动宽度模式继续保留。
- 新增一键随机和冰川蓝、薄荷绿、落日橙、柔雾紫 4 套配色。范围支持监控、时间与图标、全部文字；只对监控配色时保留系统颜色与未选指标颜色。
- 字体列表来自本机安装字体，监控可统一加粗。设置保存后在预览、Explorer 内嵌和独立监控窗中使用同样的字体配置。
- 旧配置自动采用新默认值：自动宽度开启，字体 Microsoft YaHei UI，常规字重。保留已有布局、字号、手动宽度数值、固定指标和颜色。升级前源码与配置备份在 cache/claribar/backups。

## 实际任务栏回归

使用 `scripts/probe-taskbar.ps1 -Apply -Extended -Adaptive -Watchdog`：

- 两个任务栏均插入真实监控区域。单行、双栏、双行和独立图标配色回归通过。
- 用 6 项较长回归文字模拟截图中的 GPU 频率、占用、内存、上传、下载、风扇组合。
- 手动模式按配置分配 420 像素宽度；固定等宽列可能截断长文字，属于手动限制的结果。
- 自动模式下，保留 100 像素的旧宽度数值时，微软雅黑 UI / 700 字重的真实监控宽度为 380 像素，Consolas / 400 字重为 368 像素；两块任务栏均读回 `IsTextTrimmed=false`。证明自动宽度实际忽略旧手动宽度，并响应字体/字重。
- 正常关闭与心跳中断后移除插入区域、恢复修改，回归通过。

机器可读记录位于 cache/claribar/logs：`claribar-checks.json`、`claribar-localized-sensors.json`、`claribar-ui-smoke.json`、`taskbar-adaptive-verification.json`、`taskbar-layout-verification.json`、`taskbar-property-verification.json`、`taskbar-watchdog-verification.json`。

预览图位于 cache/claribar/artifacts/ClariBar/screenshots：`colors.png`、`taskbar-settings.png`、`taskbar-preview-large.png`、`taskbar-preview-light.png`。

0.2 的 Explorer 固定驻留和系统位图图标边界仍适用，见 [基础适配记录](0.2任务栏验证.md)。本次验证不主动重启 Explorer。
