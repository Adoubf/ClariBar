# 0.5.2 字号居中与设置图标

后续修正：本版本的居中检查使用控件行框，没有包含字形伸出行框的部分。该限制会导致多行文字视觉上拥挤、偏下；0.5.3 改用字形边界，并加入实际渲染像素检查，见 `0.5.3字形与行间距验证.md`。以下保留本版本的原始检查范围。

## 修改

- 内嵌监控使用完整的任务栏高度，按实际字体测量各行高度，给整组文字分配相同的上下留白。文字在单元格中居中，行间距为 2 个逻辑像素；超出可用高度时逐步缩小字体。
- 使用紧凑的文字行边界，避免字体自带行间留白影响布局。任务栏预览采用相同的测量和布局方式。
- 系统配色设置分别使用时钟、日历、托盘展开、网络、音量、键盘和电池图标。
- 保留 0.5.1 的回车确认、点击空白保存、无效输入处理及输入框内调整按钮。

## 验证

在 Windows 11 的两个实际任务栏上运行：

```powershell
& .\scripts\build-native.ps1
& .\scripts\probe-taskbar.ps1 -Apply -Centering
```

检查 8 种组合，包括 8、13、15、24 字号，单行、双行、双栏，5/6/8 个指标，以及 Microsoft YaHei UI、Segoe UI 和 Consolas。通过实际 XAML 坐标核对整组文字的上下留白、面板位置、字体范围及省略状态。两个任务栏全部通过，上下留白差值小于 1 个逻辑像素；测试后的任务栏属性还原检查通过。

记录：`E:\haoyue\cache\claribar\logs\taskbar-centering-verification.json`；各组合的控件树保存在同目录的 `taskbar-centering-*.txt`。

自带运行库的发布版本通过六个页面的 UI 检查及两处字号编辑检查。程序内渲染截图包括 `system-color-icons.png`，以及 8、15、24 字号的 `monitor-alignment-*.png`，位于缓存目录的 `artifacts\ClariBar\screenshots`。这些截图用于检查本程序的布局和图标；未使用外部键鼠自动化。
