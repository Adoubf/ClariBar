# 0.4.0 采集、常用指标与物理出口修复

日期：2026-10-27。当前系统 Windows 11 25H2 / 26200.9711。源代码仍在 E:\haoyue\myproject\home\ClariBar；工具、构建、配置、日志与备份仍在 E:\haoyue\cache\claribar。

## 原因与修复

1. 普通权限采集无法读取本机 CPU 温度、核心频率及部分硬盘详细信息，旧界面却把原始空通道统一显示为“不可用”。现在仅提升独立采集器，授权成功后保存启动偏好；下次启动仍由 Windows 正常显示 UAC。失败或取消时自动退回基础采集，不反复请求。可在通用设置关闭启动授权。
2. 旧“常用指标”按 Temperature/Clock/Load 等类型粗筛，仍包含大量每核心、线程、DIMM、GPU 次要引擎和厂商通道。现在按设备总量与主通道明确挑选：CPU 总占用/主温度，GPU 主负载/主温度，物理内存占用，各盘总活动与读写速率，出口上下行。虚拟内存不作为物理内存占用。
3. 原固定网速来自一张旧的非出口接口。网络采集改用独立 C++ SystemMetrics 模块读取 GetIfTable2 与 GetIpForwardTable2，选取正在连接的物理以太网/WLAN 默认出口，按路由跃点数加接口跃点数排序。优先 IPv4，没有 IPv4 默认出口时使用 IPv6。每次采样重新选路并用 64 位收发计数差除以真实经过时间计算速率。
4. 不再枚举 LHM 的 VM、WSL、Hyper-V、隧道及驱动过滤网卡。物理出口计数包括真正经过该接口的虚拟机/WSL 外部流量，不把虚拟接口再次累加。没有符合条件的物理默认出口时明确显示未连接，不任意选一张有流量的卡。
5. 上下行具有稳定逻辑标识，路由切换无需重新固定。旧 `/nic/.../throughput/7` 与 `/8` 的固定项迁移为默认物理出口，保留对应颜色、名称和顺序。
6. 高级无数据通道默认隐藏，可勾选“显示无读数通道”查看。缺少权限、首次建立流量基线、接口未提供、断开和读取失败分别标记，不把它们伪装为有效零值。

## 实机结果

- Windows 路由与采集结果一致：以太网，Realtek Gaming 2.5GbE Family Controller，接口 19，默认路由跃点数 0，接口跃点数 25。
- 排除 32 个虚拟/非物理接口，只提供一组物理出口上下行；普通权限实测得到有效非零上下行。
- 普通采集返回 98 项原始传感器；完整硬件采集返回 265 项，错误列表为空。数量差异包含权限及去掉网络重复通道的影响。
- 完整采集下常用列表为 12 项，全部有有效读数：CPU 占用与温度 2 项、GPU 主负载 1 项、物理内存 1 项、两块磁盘的活动/读写共 6 项、出口上下行 2 项。
- 运行复核时 CPU 封装温度为 41°C，14 个性能/能效核心频率均有效。截图中因权限为空的温度和频率现已读取。
- UHD 770 的当前采集接口仍未返回独立 GPU 温度；能力状态明确记为接口未提供，温度值保持缺失，不使用其他硬件温度替代。
- 现有双行、字号、字体、加粗、颜色及其他固定指标保留；旧网卡固定项和配色迁移成功，硬件访问启动偏好已保存。

## 验证

- 原生模块、采集器、WinUI 设置程序、检查程序最终构建均为 0 警告、0 错误。
- 自动测试覆盖：物理默认路由与跃点数，忽略低跃点虚拟接口，IPv6 回退，无物理出口，计数基线、空闲零流量、计数重置、网卡切换，旧固定项迁移及配色保留，物理 RAM 选择，常用筛选和授权/不支持区分。
- 真实普通权限 IPC 和六页面、任务栏嵌入、字体、预览渲染回归通过。
- 正常运行的完整硬件采集通过 `ClariBar.Checks.dll --runtime` 复核：实时完整快照、CPU 温度与所有核心频率、12 项常用有效、两盘读写、物理出口唯一、启动偏好与旧网卡迁移。
- 本次不重启 Explorer，不安装额外常驻服务或计划任务，不修改代理/路由。早期任务栏适配历史记录另见 0.2 文档。

机器可读记录在 cache/claribar/logs：`claribar-checks.json`、`claribar-ui-smoke-user.json`、`claribar-broker-user.json`、`claribar-current-sensors.json`、`claribar-runtime-validation.json`、`claribar-running-check.json`。运行快照会持续更新，温度和速率随负载变化。

启动脚本使用 0.4.0。`scripts/run.ps1 -Elevated -Diagnostics -Page sensors` 可启动普通权限设置窗口并请求独立管理员采集器，同时输出运行诊断；日常双击启动即可使用已保存的启动偏好。
