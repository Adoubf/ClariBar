# 0.6 界面、自适应与过渡动画

## 交互与外观

- 使用 Windows App SDK 原生 TitleBar，合并原系统标题栏与应用顶栏，保留系统窗口按钮、拖动与窗口管理。
- 浅色顶栏沿用参考截图实测的 #ECF6F9，侧栏保留 #F3F3F3；内容区继续使用原生主题层级。外层主体与内容面板使用圆角。
- 顶栏提供帮助入口和导航折叠按钮。帮助包括使用方法、权限说明、文字配色与快捷键；F1 打开帮助，Ctrl+F 聚焦查找，Ctrl+B 展开或折叠导航。
- 导航折叠后保留六个页面图标与名称提示，偏好通过 NavigationCollapsed 保存。窄窗口自动使用图标导航，展开时作为临时面板显示。
- 关于页去掉重复名称和大 Logo，版本说明在宽窗口与页标题同行靠右，小窗口下换行。导航底部显示版本。
- 页面使用淡入与位移过渡；导航和主题切换也有过渡，遵循 Windows 的系统动画开关。

## 自适应

窗口至少 600×480。按内容宽度就地调整布局，不因窗口缩放重建整个页面或重连采集器：

- 概览与配色卡片从四列转为两列，极窄内容区转为一列。
- 设置项在窄窗口中将编辑控件移到说明下方。
- 资源监控筛选区按宽度使用一行、两行或三行；紧凑列表保留指标与设备、当前值和状态。
- 页面标题操作、预览操作和关于页版本信息在窄窗口换行。
- 任务栏预览在窄窗口隐藏示意应用图标，为监控文字与系统图标分配空间。

## 验证方法

程序的 --smoke-test 对自带运行库的发布版本执行六页基本检查、字号输入检查、窗口与帮助检查。600、900、1220、1600px 四档宽度乘六个页面，共 24 组检查控件边界与查找框宽度，并记录折叠偏好保存及实际动画时间线。

脚本 verify-shell-render.ps1 另从实际渲染的 shell-compact.png 提取导航区域像素，检查折叠后图标确实可见，并核对顶栏和侧栏颜色。该检查补充控件几何验证，防止出现“宽度缩小但导航图标隐藏”的情况。

记录均位于 E:\haoyue\cache\claribar\logs：
- claribar-shell-check.json
- claribar-shell-pixels.json
- claribar-ui-smoke.json
- claribar-font-size-check.json
